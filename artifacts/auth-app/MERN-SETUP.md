# GlobeTrek MERN setup

1. Run npm install.
2. Copy .env.example to .env and set a MongoDB connection string.
3. Start MongoDB locally or use MongoDB Atlas.
4. Run npm run dev:server for the Express API on port 5000.
5. Run npm run dev:client for the React mobile frontend on port 4173.

API routes: /api/health, /api/auth/register, /api/auth/login, /api/me, /api/universities, and /api/applications.
